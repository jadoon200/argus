# ARGUS

All-source intelligence analyst workbench: open-source collection (GDELT global news + curated world/agency RSS) + entity/event extraction + NATO-Admiralty source-reliability scoring, fused into **cited intelligence briefs** by a **multi-agent ACH deliberation panel** (LangGraph) with a free-by-default pluggable LLM backend (local Ollama, deterministic fallback, or opt-in Codex API). Sibling to `../sentinel` (cyber side); bridges to its read-only knowledge-graph API. Portfolio project oriented to Singapore's **DIS — Digital and Intelligence Service** mission. Roadmap: `docs/ROADMAP.md`. **Status: API, narrative watch, cyber-fusion bridge, and the React dashboard all live; remaining work is polish + the deferred live deployment.**

## Commands

- Conda env `argus` (Python 3.12): `make env` once, then `conda activate argus` + `make install` (pip, `requirements*.txt`). Deps are declared in `requirements.txt` / `requirements-dev.txt` — keep `pyproject.toml` in sync, and refreeze the pinned lock after changes with `make lock` (CI and Docker install from the lock).
- `make check` — ruff lint + format check, mypy (strict), pytest. Run before every commit, inside the activated env.
- `make up` / `make down` — Postgres via Docker Compose, then Alembic migration.
- `make ingest Q="<topic>"` — run the open-source ingestion Prefect flow (GDELT DOC 2.0 API for the topic + curated RSS feeds; each document tagged with its source for provenance + Admiralty rating).
- `make enrich` — entity/event extraction + dedup + Admiralty credibility scoring over ingested documents.
- `make narratives` — narrative clustering + coordination detection + DISARM influence-ops tagging (Layer 2b). `make narratives`/`main()` tag by default (inject `DisarmMapper()`); `rebuild_narratives` leaves tagging off when called with no `mapper` (slim/test paths). No env flag — tagging is guarded so a failure never breaks the rebuild. `ARGUS_DISARM_THRESHOLD` (0.28) / `ARGUS_DISARM_TOP_K` (3) tune it.
- `make brief Q="<question>"` — run the analyst agent to produce a cited intelligence brief (key judgments, evidence w/ reliability ratings, timeline, confidence, gaps). Uses the configured LLM backend; falls back to the deterministic extractive briefer with no key. **Query triage** (`agent/triage.py`, ~0.1 ms, no LLM) short-circuits before the panel: meta questions ("what can u do", "hi") get a canned capabilities answer; an empty corpus or one sharing no content token with the query gets instant collection guidance whose gaps text feeds `collect-loop` (retrieval path only — explicit-evidence callers like the eval are never gated). `POST /brief` returns triage responses with `brief_id=0`, never persisted (`/briefs` = intelligence products only).
- `make eval` — score the agent/RAG on the gold query set: retrieval recall@k, citation accuracy, faithfulness (via LLM-as-judge and opt-in NLI cross-check), source-reliability calibration; results land in `docs/EVAL.md` (including recorded negatives).
- `make collect-loop Q="<question>"` — close the loop: run an initial brief, derive search queries from its gaps, ingest + enrich, then re-brief on the expanded corpus.
- `make api` — serve the read-only FastAPI + the agent `/brief` route on `:8000` (includes `/contested` for contested-event detection; `GET /disarm/techniques` DISARM catalog; `POST /map-disarm` zero-shot tagging of pasted text; `GET /stix` STIX 2.1 bundle export of the DISARM-keyed influence-ops graph; `GET /actors` threat-actor→nation attribution registry). `POST /brief` takes `mode: auto|quick|deliberate` (default AUTO) — auto = **adaptive effort routing** (`agent/router.py` `decide_mode`, deterministic + instant, reason surfaced on the card): escalates to the panel for attribution/causality question shapes, low-reliability-only (D/E/F) sourcing, or contested framing (divergence over evidence embeddings **in the band [0.30, 0.75)** — ≥0.75 = topically scattered coverage, NOT contest; live-caught mis-route, regression-tested); everything else → quick. quick = one LLM call via `oneshot_brief` (~70-90s on qwen2.5:14b, digest backstop), deliberate/panel = full deliberation (minutes). **Collect-on-demand** (`collection/ondemand.py` `collect_for_query`, `ARGUS_AUTO_COLLECT` default on, floor `ARGUS_AUTO_COLLECT_MIN_RELEVANT`=3): <3 relevant docs → inline GDELT fetch+persist+enrich, re-retrieve, then answer — corpus is a cache, not a prerequisite; GDELT failure degrades to existing corpus, never errors. Transparency on BriefResult/BriefOut: `mode`, `mode_reason`, `auto_collected` (response metadata, not persisted). EvidenceItem carries `embedding` from the Document row for the divergence signal. NB in tests: patch `argus.agent.analyst.collect_for_query` (and `argus.collection.ondemand.fetch_gdelt_articles` for /ingest) or tests hit real GDELT. `POST /ingest` (guarded like /brief; upstream failure → 502) = GDELT fetch + persist + enrich from the dashboard — the Collection view has an "Ingest a topic" box, so the UI is self-sufficient without the CLI. Section parser (`_match_header`/`_parse_sections`) tolerates markdown-decorated headers (`**KEY JUDGMENTS:**`, `## ...`) — live qwen emitted these and parsed to 0 judgments before. Workbench renders triage cards as plain chat messages ("instant" tag, no tradecraft chrome) and shows the raw body inline when no judgments parse.
- `make ui` — React/TS dashboard dev server on `:5173` (needs `make api` running).
- `alembic revision -m "..."` / `alembic upgrade head` — migrations live in `migrations/versions/`.

## Layout (planned; ✅ = scaffolded, ⬜ = not yet)

- ✅ `src/argus/config.py` — pydantic-settings; all config via `ARGUS_*` env vars / `.env`.
- ✅ `src/argus/logging.py` — structlog console logger (`get_logger`).
- ✅ `src/argus/sources.py` — curated source registry: provenance label -> publisher metadata + NATO Admiralty reliability grade (A-F); `grade_for`/`info_for`. Conservative (no open source graded A; unknown -> F).
- ✅ `src/argus/db/` — SQLAlchemy 2.0 models (`models.py`: sources, documents, entities, events, narratives + edges), session helpers (`base.py`). Models use `JSON().with_variant(JSONB, "postgresql")` so DB tests run on in-memory SQLite.
- ✅ `src/argus/ingest/` — `gdelt.py` (query-driven DOC 2.0 `ArtList` API; source = article domain), `rss.py` (curated world/agency feeds via defusedxml; source = feed label), Prefect flow in `flows.py` (`persist` inserts *new* docs only, never clobbering enrichment; `ensure_sources` upserts graded Source rows for the FK). httpx + tenacity (`reraise=True`); respx-mocked tests + a live smoke-tested path. Run: `make ingest Q="<topic>"`.
- ✅ `src/argus/nlp/` — dense embeddings (`embed.py`, lazy sentence-transformers MiniLM, L2-normalised), entity extraction (`extract.py`, spaCy with a dependency-free heuristic fallback), event dedup/clustering (`events.py`, greedy cosine + time window; distinct-source corroboration), Admiralty scoring + labels (`reliability.py`, credibility 1-6 as a corroboration proxy), hybrid BM25 + dense retrieval with RRF and tie-aware ranks (`retrieval.py`), DISARM influence-ops tagging (`disarm.py`, curated Red Framework technique registry + zero-shot bi-encoder mapper + lexical fallback), and the orchestration entrypoint `enrich.py` (`run(session)` is testable; `make enrich`). Idempotent: embedding/entities touch only un-enriched docs; events are a full rebuild.
- ✅ `src/argus/narrative/` — narrative watch (Layer 2b): `cluster.py` groups documents by shared *framing* (greedy cosine, looser than event dedup, no time gate, min cluster size), `coordination.py` scores each narrative's coordination = burstiness * (0.5 + 0.5 * low-reliability share) — a transparent HUMAN-REVIEW signal in [0,1], never an automated verdict of inauthenticity. `run.py` rebuilds Narrative/NarrativeDocument rows (`make narratives`); surfaced at `GET /narratives` (most-coordinated first).
- ✅ `src/argus/nlp/contest.py` — contested-event detection (inverse of narrative watch): `framing_divergence()` measures how far apart the sources' embeddings are within one event (1 - minimum pairwise cosine); high divergence across reliability tiers (high-tier vs low-tier sources disagreeing on the same event) signals deception/error/developing story. Deterministic, no LLM, stored on `Event.divergence` (migration `0003`); surfaced at `GET /contested` (most-contested first, threshold `ARGUS_CONTESTED_THRESHOLD`) and as `divergence` on `/events`. Human-review signal only.
- ✅ `src/argus/agent/` — **multi-agent ACH deliberation on LangGraph**: hypotheses (`num_hypotheses`) → **ACH diagnostic scoring** (`ach.py`: an evidence×hypothesis consistency matrix → hypotheses ranked by least *reliability-weighted disconfirming* evidence, so a low-reliability source can't sink a hypothesis) → analyst ↔ red-team → adjudicator, wired in `graph.py` over pure node functions (`nodes.py`). The debate loop rebuts every red-team challenge — the analyst answers each critique (including the last) before the neutral adjudicator decides (`debate_rounds` = number of challenges). Red-team critiques are **structured** (`Critiques` schema: target/severity/citations) and the adjudicator must answer the strongest one (`Finding.critique_response`). Each role samples at its own temperature (hot red team, cold adjudicator). Role system prompts in `personas.py` are specialized for OSINT/geopolitical intelligence — Analysis of Competing Hypotheses, a Key Assumptions Check, Indicators & Warnings, and IC estimative language (ICD 203); the structured `Finding` (`schemas.py`) carries all of these. `llm.py` is the **free-by-default** pluggable backend: `auto` = local Ollama if reachable, else deterministic template (and **never** a remote/paid backend automatically). Opt-in via `ARGUS_LLM_BACKEND`: `mlx` (Apple-Silicon-native `mlx-lm`; also the path to serving a locally MLX-LoRA-fine-tuned model), `openai` (any OpenAI-compatible server — vLLM/llama.cpp/LM Studio/groq — via `ARGUS_OPENAI_BASE_URL`), `anthropic` (Codex, paid). All implement `complete(system, user, response_schema=None, temperature=None)` so structured outputs and per-role sampling work uniformly. **Deliberation resilience** (`structured.py` `complete_model` now catches backend failures: httpx timeout/connection, OSError; every LLM call degrades gracefully to empty; `analyst.py` `_deliberate_or_digest()` wraps the multi-agent panel so a `/brief` ALWAYS returns a cited digest, never a 500 on timeout; LLM timeout raised 180s → 300s to avoid race on large structured outputs). `analyst.py` gathers evidence by hybrid retrieval (capped per source for diversity via `brief_max_per_source`), runs the deliberation (or a labelled deterministic digest with no LLM), and assembles the brief — enforcing **citation resolvability**: agents cite short `[E#]` labels (LLMs copy these reliably; long hash ids they don't), resolved back to real doc ids (tolerant of `1`/`E1`/`[E1]` variants); anything unresolvable is dropped. Free-text citation parsing now stricter — a bare number inside prose like `[2 vessels]` no longer mints spurious citations; brackets resolve bare numbers only when every token is a label/number/doc-id (pure citation list). The ACH scorer similarly now DROPS matrix cells with unresolvable evidence labels and tolerates label variants. The hypothesis + adjudicator steps use **structured JSON outputs** — pydantic schemas (`schemas.py`) via Ollama's `format`, with a graceful free-form text fallback (`structured.py` + `nodes.py`), so briefs are reliable across models. **Self-consistency confidence calibration** (`assurance.py`): opt-in "high-assurance" mode (`ARGUS_ASSURANCE_SAMPLES` > 1) samples the adjudicator K times and derives confidence from *agreement* (unanimous → reported level unchanged; wobbly < 2/3 → reported one level lower), honest calibration over a lucky single draw. **Citation precision**: the adjudicator prompt now requires citing an item ONLY if it *directly* supports the specific judgment, not tangential/topic-adjacent citations. `make brief Q="..."`. NOTE: pull a capable instruct model — recommended `ollama pull qwen2.5:14b` (M3 Pro); `llama2` is too weak for the analysis.
- ✅ `src/argus/actors.py` — **threat-actor → nation attribution registry** (cross-graph join, parallel to `sources.py`): ~16 well-known nation-state groups (APT28/Fancy Bear→Russia, Lazarus→North Korea, Volt Typhoon→China, OilRig→Iran, …) with vendor aliases. `resolve_actor(name)`, `attributions_in_text(text)` (word-boundary alias scan, deduped — `APT1` never matches inside `APT10`), `actors_for_nation()`. Wired into the cyber-fusion bridge: a SENTINEL campaign naming a group is annotated `— <Nation>` (title) + "Attributed in open reporting to … (contested, human-review)" (summary), so a cyber campaign links to the geopolitical actor of the brief. Surfaced at `GET /actors`. Attribution = open-reporting consensus, contested, human-review — never an automated verdict.
- ✅ `src/argus/stix.py` — **STIX 2.1 export** (`to_stix_bundle`, `GET /stix`): serializes the DISARM-keyed influence-ops graph — DISARM techniques → `attack-pattern` (external_references to DISARM + `kill_chain_phases` carrying the DISARM phase), sources → `identity` (Admiralty reliability in description), tagged narratives → `report` (object_refs to their techniques). Hand-built (no `stix2` dep, zero-cost rule) but conformant; deterministic UUIDv5 ids so re-exports are stable/diffable. Read-only; ingestible by OpenCTI/MISP/ATT&CK Navigator; joinable with SENTINEL's ATT&CK STIX in one object model (cyber + cognitive). Only narratives with ≥1 DISARM tag become reports (STIX requires non-empty object_refs).
- ✅ `src/argus/bridge/sentinel.py` — **cyber-fusion bridge** (Layer 7): a read-only client for the sibling SENTINEL knowledge-graph API. When `ARGUS_SENTINEL_API_URL` is set, `cyber_evidence()` augments a brief's evidence with SENTINEL cyber campaigns (mapped to rated `EvidenceItem`s the analyst can cite) — one brief fuses open-source + cyber. Parses SENTINEL's real `/campaigns` schema: ATT&CK `technique_id`s out of the technique objects, plus `kev_cves` (confirmed exploitation in the wild — surfaced as `[KEV]` and lifting the evidence credibility) and `age_days` (recency); SENTINEL returns all campaigns sorted most-salient first, so the bridge caps client-side. **Query-relevant**: the brief's question is mapped through SENTINEL's `POST /map-techniques` (zero-shot ATT&CK) and only campaigns whose techniques overlap the mapped ones (above `sentinel_relevance_min_score`) are kept — so a cyber question pulls the relevant campaigns and a geopolitical one pulls none (mapper down → falls back to salience, never suppresses blindly). Off by default; never breaks a brief (unreachable → []). ARGUS only READS from SENTINEL. (Validated end-to-end against a live SENTINEL instance, not just mocks.)
- ✅ `src/argus/collection/` — closing-the-loop collection tasking: `tasking.py` `derive_queries()` converts a brief's intelligence gaps + collection requirement into targeted open-source search queries (structured LLM call with a deterministic named-entity fallback via regex on capitalized spans); `loop.py` `run_collection_loop()` runs initial brief → derive queries → GDELT ingest each → enrich → re-brief on expanded corpus, so the agent tasks its own collection instead of stopping at "we don't know." Free/local end-to-end. Command: `make collect-loop Q="<question>"`.
- ⬜ `src/argus/agent/tools.py` — interactive agent tools (`get_entity`, `get_timeline`, `query_narratives`); the spine retrieves evidence up front (incl. cyber via the bridge), so tool-calling is a later extension.
- ✅ `src/argus/eval/` — fixture gold set (`goldset.py`, incl. a calibration TRAP: a single low-reliability state-affiliated source the agent must NOT overstate), deterministic scorers (`metrics.py`: recall@k, MRR, citation coverage, fabrication markers, confidence-cap), LLM-as-judge for **faithfulness** + **citation support** (`judge.py`: reads each key judgment against evidence, returns structured `{grounded, supported}` verdict; free/local Ollama; runs when backend available), **deterministic NLI cross-check** (`nli.py`: cross-encoder entailment scorer (`cross-encoder/nli-deberta-v3-base`, lazily loaded, opt-in `ARGUS_NLI_ENABLED`); judges claim–evidence entailment for each key judgment and cited [E#] evidence independently of the LLM judge, reported alongside LLM metrics; contains `ENTAILMENT_GOLD` hand-labelled 10-pair slice + `agreement()` helper for measuring judge–human accord), runner + markdown report (`run.py`, `make eval`). Retrieval metrics are LLM-free (CI-safe); brief metrics use whatever backend is available. Gold set expanded 3→10 queries / 6→20 docs (6 calibration/contested caps) so metrics are means over many cases. Latest recorded LLM-path (qwen2.5:14b, 10-query): recall@3 1.00 over 20 docs, coverage 1.00, calibration held 5/6 caps (lone breach = power-outage sabotage trap → moderate, reproducible across runs → a specific state-attributed-sabotage blind spot to fix), faithfulness 0.70, citation support 0.60; NLI slice (10 atomic pairs, agreement with human labels): NLI 0.90, LLM-judge 1.00 (NLI's value is determinism/independence, not per-item accuracy). BUT on FULL briefs strict-entailment collapses (faithfulness 0.30, citation-support 0.10, labelled experimental) — NOT a bug (citations resolve as E#, verified) and NOT unfaithful briefs: analytic key judgments synthesize/hedge beyond any single evidence line, so strict NLI entailment marks them neutral (e.g. a sound reef synthesis scored 0.00 vs all 3 sources). Whole-judgment NLI is not a valid faithfulness metric for analytic writing; FIX BUILT: `decompose()` splits each judgment into atomic sub-claims (deterministic clause split + hedge strip, RAGAS shape), `score_brief_nli(decompose_claims=True)` scores each → faithfulness = fraction of sub-claims entailed; `make eval` reports atomic + strict. Validated: reef judgment strict 0.00 → atomic 0.50 (grounded fact 0.98, ungrounded inference 0.00). Next: better decomposer (clause split crude; LLM decomposer = RAGAS-faithful but adds a model dep). Template-path baseline: recall@3 1.00, coverage 1.00, 0 fabrications, 0 trap breaches; detailed results in `docs/EVAL.md`.

## Conventions

- Branching: `main` is deployable; work on `feat/<topic>` branches, merge via PR.
- CI: `.github/workflows/ci.yml` runs the full gate (ruff + ruff-format + mypy strict + pytest) on ubuntu for pushes/PRs to `main`, installing the pinned `requirements.lock`. Frugal by design (ubuntu-only, single Python, cancel-in-progress) — keep it that way. A migration↔model parity test (`tests/test_migration.py`) fails CI on schema drift.
- mypy strict everywhere; the Prefect decorator exception (if needed) is scoped in `pyproject.toml` — don't widen it.
- Every ingester: httpx + tenacity retry, parse into ORM objects, upsert with `session.merge`, unit test with mocked payload.
- **Zero-cost rule:** free data sources and free/local models only. The LLM/agent layer is pluggable and **must run end-to-end with no paid key** — the deterministic extractive briefer is the always-available fallback; `auto` mode prefers local Ollama and falls back to the template, never touching the paid Codex backend. Codex API stays strictly behind `ARGUS_LLM_BACKEND=anthropic` + a key, never required, never in CI.
- **Honest-evaluation discipline:** every agent/model claim is reported on the number that survives scrutiny (citation accuracy, faithfulness, retrieval recall, reliability calibration), with recorded negatives, in `docs/EVAL.md`.
- **Responsible-use constraint:** public/open-source data only; defensive/analytical only; no targeting of individuals, no auth-gated scraping, no offensive tooling. Coordination signals are human-review decision support, never automated verdicts.
- Large artifacts (datasets in `data/`, model caches, embeddings) never go in git.

## Sibling bridge (Sentinel)

The `query_cyber_graph` agent tool calls Sentinel's existing **read-only** API (`/campaigns`, `/techniques`, …) — base URL via `ARGUS_SENTINEL_API_URL`, off by default. ARGUS never writes to Sentinel; it only reads, so the cyber graph stays the system of record for the cyber side.
